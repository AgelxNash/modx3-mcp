# MODX MCP manager screenshots

Four localized documentation images are provided: dashboard and dependency graph for Russian (`-ru`) and English (`-en`).

These are browser renderings of the MODX MCP manager templates and graph visualizer with data from a test installation (141 nodes, 119 links). The API endpoint was replaced with `https://example.com/assets/components/modxmcp/api.php`; all token characters were replaced with a fully masked placeholder. Images are intended only as illustrations, not as evidence of an authenticated manager session or of current client connectivity. The English graph labels were localized in the documentation rendering; full graph label localization remains outside the 1.2.2 distribution.

To avoid exposing user credentials or internal URLs, do not replace the images with unmanaged screenshots. Capture screenshots only after checking all visible URLs, secrets, and site-specific data.
