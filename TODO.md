## Интерфейс компонента в менеджере MODX

- **Статус:** закрыто в 1.2.2 (2026-10-12).
- **Обнаружено:** 2026-10-10, после установки MODX MCP 1.2.1 из ModStore.
- **Проблема:** административный интерфейс MODX MCP отображается не полностью, неудобен и непонятен.
- **Решение:** адаптивная двухколоночная панель, отдельный граф связей и прокрутка внутри менеджера. Исправления установлены и проверены на тестовых MODX 2.8.9 и MODX 3.2.4, включены в оба транспортных пакета `1.2.2`. Состояние «MCP включён» не выдаётся за проверку подключения конкретного клиента. См. [интерфейс](README.ru.md#интерфейс-modx-mcp) и [релиз](https://github.com/rumata-estor/modx3-mcp/releases/tag/v1.2.2).

## Ссылки в окне установки транспортного пакета

- **Статус:** закрыто в 1.2.3 (2026-10-12).
- **Обнаружено:** 2026-10-10, при установке MODX MCP 1.2.1.
- **Проблема:** относительные ссылки из README и CHANGELOG открываются относительно домена сайта MODX, а не GitHub. Пример неверного адреса: `https://modx3.alex-palochkin.ru/master/CHANGELOG.ru.md`.
- **Решение:** `_build/transport.documentation.php` преобразует относительные ссылки в README и CHANGELOG в абсолютные ссылки GitHub **только для метаданных новых пакетов**. PHP-тест и проверки административного интерфейса подключены к GitHub Actions и успешно пройдены. Оба пакета для MODX 2/3 собраны, установлены на тестовые сайты и проверены: работают ссылки на оба языка, изображения и историю изменений; 16/16 настроек и действующие токены сохранены. Исправление опубликовано в патче 1.2.3; архивы предыдущего релиза 1.2.2 не менялись.

## Первоначальное получение API-токена после установки

- **Статус:** закрыто в 1.2.2 (2026-10-12).
- **Обнаружено:** 2026-10-10, при чистой установке MODX MCP 1.2.1.
- **Проблема:** компонент автоматически создаёт API-токен при установке, но в интерфейсе управления показывает только маску (начало и конец токена). Пользователь не может скопировать полный первоначальный токен для подключения MCP-клиента и вынужден выпускать новый.
- **Решение:** кнопки «Показать» и «Скопировать» получают существующий токен по отдельному запросу менеджера с правом `settings`; полный токен не включён в исходный HTML. Новый токен генерируется только по явному действию с предупреждением о разрыве старых подключений. Платформенные процессоры предусмотрены для MODX 2 и MODX 3. Проверены сборки и работа MCP после установки; полный автоматический тест нажатий в менеджере не заявляется.

## Документация системных настроек MODX MCP

- **Статус:** закрыто (2026-10-12); справочники для версии 1.2.2.
- **Обнаружено:** 2026-10-10, при первоначальной настройке MODX MCP 1.2.1.
- **Проблема:** системные настройки компонента в менеджере MODX недостаточно понятны без подробных объяснений; пользователю трудно определить, что именно регулирует параметр и когда его менять.
- **Решение:** созданы [русский](docs/SETTINGS.ru.md) и [английский](docs/SETTINGS.md) справочники всех 16 настроек: значения по умолчанию, поддерживаемые значения, влияние на работу, риски и рекомендации. Полнота сверена с общим для MODX 2/3 файлом `_build/data/transport.settings.php`, ссылки добавлены в README и обе инструкции установки. Код административного интерфейса не менялся.
